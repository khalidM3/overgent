# L2 hosted Project service evidence — 2026-08-23

Result: **PASS proposed** for the documented L2 exit behaviors implemented by
this lane. Integration and merge remain owned by the root integrator.

## Delivered behavior

- Convex schema and indexes for Projects, members, devices, invites, one-time
  dashboard tickets, browser sessions, workspaces, repository scopes,
  workstreams, staged/active manifests and chunks, append-only activity,
  deterministic findings, semantic objects and separate embeddings,
  coordination deliveries, cursors, and rate limits.
- Frozen `/v1` HTTP actions for Project creation, invite creation, enrollment,
  dashboard-ticket exchange, bootstrap, event batches, heartbeat, Project
  changes, workstream briefs, context-item fetch, and device revocation.
- Server-generated invite/device/ticket/session secrets with only SHA-256 hashes
  stored. Creator devices use the high-entropy caller-generated bearer required
  by the frozen authenticated `POST /projects` contract.
- Edge rate counters commit in a separate transaction before authentication or
  sensitive mutation work, so failed brute-force attempts consume quota. Domain
  mutations retain an additional rate guard for successful calls.
- Actual and declared request-byte limits, exact object-key/count/string/path
  validation, event allowlisting, schema-version validation, and recursive
  prohibited-field rejection.
- Server-derived device/Project membership authorization. The untrusted event
  envelope cannot select the stored member, Project, workspace, or repository
  scope.
- Transactional event-ID dedupe and acknowledgement, durable acceptance of valid
  out-of-order events, and sequence-aware projection rules that prevent stale
  state rollback.
- Atomic per-workstream manifest activation after exact chunk sequence/count and
  Gate B-compatible SHA-256 content-hash validation. A 1,000-path manifest uses
  ten 100-entry chunks and replaces the previous active revision in one
  transaction.
- Repository-scope context revisions advance only with material projection
  changes. Routine activity, retries, and repeated identical state do not bump
  them.
- Stable deterministic same-path finding fingerprints/upsert, structural
  evidence, and authorized workstream brief/context-item retrieval.
- Indexed, bounded retention sweep scheduled every five minutes. Child manifest
  chunks and semantic embeddings are ordered before their owning rows; each run
  deletes at most 200 expired records.
- Structural operation with semantic providers absent. Semantic objects and
  vectors remain separate; embedding dimension/index/provider activation stays
  at L6 under ADR-018.

No OpenAPI, JSON Schema, generated protocol contract, Go local core, dashboard,
or root legal file was changed.

## Security and privacy

- The live harness generates synthetic IDs, tokens, summaries, paths, and
  repository fingerprints at runtime and refuses any deployment whose hostname
  is not `127.0.0.1` or `localhost`.
- Invite secrets use 128 random bits; device and browser-session secrets use 256
  bits; dashboard tickets use 192 bits. Raw values are returned only through the
  contract response/cookie that creates them and are never persisted or logged
  by backend code.
- Browser cookies are `HttpOnly`, `Secure`, `SameSite=Strict`, path-scoped, and
  time-bounded. Dashboard tickets are transactionally single-use.
- Every HTTP operation has a rate guard and size boundary. Authenticated
  operations derive authority from the hashed bearer and current server state;
  cross-Project and revoked-device requests fail.
- `.env.local`, `.convex/`, generated Convex bindings, `node_modules/`, and build
  artifacts are ignored. Evidence contains no credential, URL, environment
  value, customer data, source/diff, prompt, transcript, or raw command/test
  output.

## Honest limits carried forward

- The frozen enrollment/bootstrap responses do not disclose a member ID even
  though event envelopes carry one. The backend therefore treats the envelope
  member ID as untrusted metadata and derives the canonical member from the
  authenticated device plus Project. A future contract change, if desired, is
  integrator-owned; this lane did not alter the frozen schemas.
- The frozen API has device revocation but no invite-revocation or Project-delete
  endpoint. The schema supports invite revocation and deleting-state semantics,
  but those public lifecycle operations cannot be invented in this lane.
- Cleanup selection, expiry ordering, and bounded-table coverage are unit-tested;
  the scheduled mutation compiled on real Convex. The live suite does not expose
  a test-only public cleanup bypass, so it does not inject expired database rows.
- L2 intentionally stores no embeddings and calls no embedding/adjudication
  provider. A production vector index dimension is not frozen before L6 provider
  selection.
- Local anonymous deployment behavior does not prove hosted availability,
  regional behavior, or cost. Rate thresholds and retention batch frequency need
  hosted load/soak measurement before beta.
