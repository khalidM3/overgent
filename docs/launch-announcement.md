# Launch announcement draft

## Livestream description

Overgent is open-source air traffic control for teams working with coding agents: install it with `curl -fsSL https://overgent.com/install.sh | sh`, start local by default, and choose team mode only when you want to coordinate with others. It shares only derived coordination facts—never source files, raw diffs, Git objects, prompts, transcripts, credentials, or command output. Report bugs and feature requests through this repository's GitHub Issues, and report vulnerabilities through the private channel in [SECURITY.md](../SECURITY.md).

## GitHub Discussions welcome post

Welcome to Overgent. It helps Codex and Claude Code sessions catch overlapping edits, stale contract assumptions, and duplicated work before merge time, without taking control of the agents or uploading the work itself. Install with `curl -fsSL https://overgent.com/install.sh | sh`; a local Project stays on your Mac, and you can create or join a team Project when collaboration calls for it. Please use GitHub Issues for bugs and ideas, and the private reporting path in [SECURITY.md](../SECURITY.md) for vulnerabilities.
